# archlinuxarm-docker

Unofficial docker image for Arch Linux ARM

#### Supported arch and tags
- `arm64`, and `arm/v7` are supported
- `latest` tag is always the most recent version currently available. pull with:

      docker pull ghcr.io/arfshl/archlinuxarm-docker:latest

-  tags with build date are also available, example: `20260521`

       docker pull ghcr.io/arfshl/archlinuxarm-docker:20260521
